# Questions ouvertes & décisions

Journal vivant du cadrage. ✅ = décidé (et reporté dans design/), ❓ = ouvert.

## ✅ Décidé
- Solo vs IA, navigateur, partage par lien (GitHub Pages).
- Duel 2–5 min, campagne longue à difficulté croissante.
- Tour par tour ; cartes autonomes avec personnalité ; le joueur pose puis regarde.
- Ordre d'action gauche → droite par défaut.
- Points de vie ; général au choix du joueur.
- Énergie obtenue en sacrifiant une carte (pas de terrains).
- **Le TCG prime sur le lore.** Le monde d'Himiko = contexte uniquement ; aucun camp en gameplay.
- Campagne = le joueur (humain du monde moderne) affronte d'autres humains avec leurs decks.
- Aucun argent réel. Monnaie de jeu → boosters.
- Boosters : oui. Fusion/XP : possible. Idle : optionnel, plus tard.
- Assets libres de droits ; IA seulement si vraiment nécessaire.
- Terrain : 1 ligne de 7 cases, effets de case possibles.
- Stats : PV, Attaque, Coût + attributs annexes (race, type, élément, pouvoir, effets).
- Hiérarchie : 1 Général, 2 Colonels, 4 Lieutenants. Grade temporairement libre pour toute carte.
- Deck 30, main 7, pioche 1/tour. Déploiement : agit au tour suivant (sauf passif).
- Boosters : 5 cartes, 1 gradé garanti ; raretés Commune → Mythique, indépendantes du grade.
- Le Roi = le joueur, avec ses PV (100-250) ; gradés = cartes normales sur les 7 cases, effets dédiés possibles.
- Budget stats : ≈ 10 ATK + 10 PV par énergie.
- 1 offrande par tour (exceptions rares, très contraintes).
- Énergie persistante (mode terrain). Deck = 23 normales + 7 gradés. Pas de contre-attaque.
- Ciblage par défaut : en face > centre > Roi ; « le plus fort » = PV > ATK > face > centre > gauche. Cas limites tranchés (voir 01-rules).
- Personnalités de départ : Brave, Lâche, Gardien, Assassin, Rancunier, Berzerk, Fidèle, Stratège, Défensif, Passif.
