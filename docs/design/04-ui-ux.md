# UI / UX

## Écrans (menu, partie, collection, deck-building, options…)
Seul l'écran de duel existe (prototype). À concevoir : deck-building (désigner les gradés), collection, ouverture de boosters, carte de campagne, partie « hors duel » (voir OPEN-QUESTIONS).

## Écran de duel : décisions validées
- **Présentation « Joueur contre IA »** : camp adverse en haut, camp du joueur en bas, 14 cases (7 + 7) face à face.
- **Cases centrales** : bouclier 🛡️ et même couleur sur les deux camps.
- **Pioche à droite de la main**, **cimetière à gauche** ; clic = voir le contenu (pioche : contenu trié, ordre caché). Le cimetière adverse est consultable.
- **Aperçu de cible** : survoler une case libre avec une carte sélectionnée montre qui elle frapperait.
- **Zone de texte** sur la carte pour décrire ses effets.
- Vitesse ×2 des animations.

## Pistes ultérieures (validées en principe)
- **Glisser-déposer** pour poser/sacrifier les cartes (sensation de manipuler les cartes) ; apparence moins « fade ».
- Responsive mobile.
- Accessibilité (contrastes, daltonisme, taille du texte).
