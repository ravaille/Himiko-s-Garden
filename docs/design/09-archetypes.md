# Archétypes et types

> Les **types** (entre crochets) sont **transversaux aux races** : un Oni peut être [samourai], un Démon ou un Humain peuvent être [mage] ou [ninja].
> Seuls quelques archétypes sont propres à une race. Un archétype = une façon de gagner + les types et mots-clés qui la servent.
> ✅ = décrit par Romain · 💡 = proposition de Claude (à valider).
> Références : Magic et un jeu Steam (non essentiel) pour le jeu ; esthétique Yu-Gi-Oh! mais avec le **Japon** comme thème central.

## Décisions (2026-11-27)
- **Déclencheur « à chaque sort lancé »** : validé (mages, Démons, bâtiments).
- **Pacte** : des **PV (du Roi) contre** une invocation, de la puissance ou un autre effet bénéfique.
- **Ronin** : conditions du type « nombre d'unités alliées ≤ N ».
- **Type ≠ mot-clé** : le *type* [vampire] donne les synergies ; le *mot-clé* « vol de vie » donne le comportement. Une carte peut avoir l'un sans l'autre.
- **IRL** : personnages **fictifs très inspirés** de personnes réelles ; **cachés pour l'instant** (ne pas les écrire dans le repo public).
