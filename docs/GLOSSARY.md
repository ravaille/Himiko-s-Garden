# Glossaire

Vocabulaire officiel : un terme = un sens, utilisé de la même façon dans les docs, le code et l'UI.

| Terme (FR) | Identifiant code (EN) | Définition |
|---|---|---|
| Roi | `king` | Le joueur. A ses propres PV ; on perd quand ils tombent à 0. |
| Général / Colonel / Lieutenant | `general` / `colonel` / `lieutenant` | Grades (1 / 2 / 4 par deck de 30). Désignés au deck-building. |
| Offrande | `offer` | Sacrifier une carte de la main pour augmenter l'énergie maximale. 1 par tour. |
| Énergie | `energy` | Ressource pour poser des cartes. Persistante. |
| Déploiement | `deployedOn` | Une carte posée n'agit qu'au tour suivant (sauf Haste/passif). |
| Cimetière | `graveyard` | Cartes mortes ou sacrifiées. |
| Personnalité | `personality` | Comportement autonome d'une carte en duel. |
| Race / Type | `race` / `types` | Race (Humain, Yokai…) et archétype (Guerrier, Chats…) servant aux synergies. |
| Mot-clé | `keyword` | Comportement récurrent (Haste, Multihit, Bushido…). |
| Case centrale | `CENTER_SLOTS` | Les 3 cases du milieu (2, 3, 4) : atteignables par défaut par les attaquants. |
| Pioche vide | `fatigue` | Échec de pioche : −10 PV au Roi. |
